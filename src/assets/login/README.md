# Login imagery

The login mosaic uses locally stored, optimized WebP copies of photographs that
are free to use under the Unsplash License.

- `checkout.webp`: [Blake Wisz — customer paying at a retail POS](https://unsplash.com/photos/tE6th1h6Bfk)
- `inventory.webp`: [Adhitya Sibikumar — worker stocking supermarket produce](https://unsplash.com/photos/aL6mtBt6gds)
- `receiving.webp`: [Eric Prouzet — boxed merchandise in a shop](https://unsplash.com/photos/d-1zXZmbAWc)

The files are cropped and color-treated by the application layout. Keep this
source record with the assets if the imagery is replaced or redistributed.
